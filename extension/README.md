# UI EATER · Chrome 扩展版

把当前网页变成小怪物的游乐场。点击「开始游戏」后，怪物才会出现，寻找按钮、文字等可吞噬元素。你可以拖动它、亲手投喂，并指定它的下一口；每次进食都会积累成长值，让它变大、变色并进化出新的形态。它与项目原有的三关虚拟桌面游戏并列，是一个独立的 Manifest V3 扩展模式。

## 构建与本地加载

在 `ui-eater` 项目根目录运行：

```sh
npm install
npm run build:extension
```

1. 在 Chrome 打开 `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择项目中的 `dist-extension` 文件夹。
5. 打开一个普通的 `http://` 或 `https://` 网页，点击工具栏中的 UI EATER 图标。

这是本地加载的开发版本，未发布到 Chrome 应用商店。已安装旧版时，先重新构建或解压新版，再在扩展管理页面点击「重新加载」，然后刷新已打开的网页，以载入新的怪物与控制条。

## 使用方式

- **开始游戏**：只在当前标签页注入小怪物并启动。仅打开扩展弹窗不会启动游戏，也不会自动吞噬页面。
- **暂停一下 / 继续游戏**：暂停或恢复怪物的移动、寻找和吞噬。
- **停止并恢复网页**：停止本次游戏并恢复扩展临时隐藏的元素。页面布局会保留，吞噬效果不修改网站数据库。
- **拖动怪物**：按住网页上的小怪物，把它拖到希望探索的位置，松开后继续活动。
- **轻点怪物**：点击小怪物，触发开心的互动反馈。
- **投喂诱饵**：在网页控制条点击「投喂诱饵」，再点击网页中的位置放下食物。小怪物会优先追过去吃掉诱饵；诱饵不会隐藏下面的网页元素。
- **指定下一口**：在网页控制条点击「指定下一口」，再点击一个可吞噬的网页元素。该元素成为优先目标，选择时会阻止这次真实网页点击，避免同时打开链接或触发按钮。表单、输入框等受保护元素仍不能被选中。
- **取消选择**：在投喂或指定模式下，按 `Esc` 或点击控制条的「取消」退出；暂停也会取消尚未完成的选择。
- **状态与计数**：弹窗与网页控制条显示进化状态。弹窗还显示当前页面域名、已吞噬网页元素数、已吃诱饵数及正在进行的活动。

关闭弹窗后，已经启动的游戏仍在当前网页中继续；需要结束时重新打开弹窗并点击停止。刷新页面或导航到其他页面后，需要手动重新点击「开始游戏」。不会在浏览器启动或页面加载时自动运行。

## 成长与进化

每吃掉一个网页元素或一份诱饵获得 **1 XP**。进化由真实吞噬完成触发，投下诱饵或选中目标本身不会增加 XP。

| 累计 XP | 形态变化 |
| --- | --- |
| 0–2 | 饥饿幼崽：浅绿色的小团子 |
| 3–6 | 萌芽小兽：长出嫩芽，变为青绿色 |
| 7–11 | 角角大胃王：长出双角，变为蓝色 |
| 12–17 | 飞翼吞吞：长出翅膀，变为淡紫色 |
| 18 及以上 | 桌面吞噬王：获得王冠，变为珊瑚色，达到最终形态 |

进化时有短暂的变身反馈，体型随阶段增大；最终形态约为初始的 1.65 倍。进度条展示距离下一阶段的成长进度，最终形态仍可继续进食。暂停保留成长，停止并恢复网页后重新开始，或刷新、导航页面，都会重新从初生形态开始。本版没有跨网页的永久养成存档。

## 适用范围

支持允许扩展运行的普通 HTTP / HTTPS 顶层网页。Chrome 内部页面、扩展管理页、新标签页、Chrome 应用商店等受浏览器保护的页面不能运行；`file://` 本地文件和其他协议也不在本版本支持范围内。

怪物通过网页中的 DOM 元素识别可吞噬目标。跨页面的 iframe 内容、canvas 内部绘制内容和关闭的 Shadow DOM 不属于本版本的遍历范围。个别由网页自行频繁重绘的控件，表现可能随原网站更新而变化。

「恢复网页」恢复的是本扩展在当前文档中临时隐藏或设为不可交互的 UI。它不会撤销用户在网站中已经完成的提交、删除等真实业务操作。扩展的吞噬动画本身不调用这些控件的点击行为。

## 隐私与权限

扩展在本机处理当前网页，不上传网页内容，不调用模型 API，也不需要账号、后台服务或浏览历史权限。

使用 `activeTab` 和 `scripting` 权限，在你点击开始后操作当前标签页；不申请所有网站的持久访问权限，不使用后台常驻工作线程，也不依赖浏览器存储权限。

## 开发与检查

```sh
npm run test:extension
npm run build:extension
```

`protocol.ts` 定义弹窗与页面之间的 `STATUS`、`START`、`PAUSE`、`RESUME`、`STOP` 消息以及包含成长值、进化和互动模式的状态快照。`popup.ts` 管理当前标签页、按钮交互和不重叠的状态轮询；弹窗关闭时停止轮询。页面端负责独立的怪物实例、目标选择、投喂、拖动、吞噬、进化和恢复。

每次开始都需要用户主动操作。弹窗初次打开只发送状态查询；暂停、继续和停止不会重新注入脚本。页面端重复注入保持幂等，避免产生重复的小怪物。

自动测试覆盖手动启动边界、状态机、DOM 恢复、成长阈值、互动输入，以及弹窗的进化状态与进度显示。验证页模拟 Chrome 消息边界；实际 Chrome 的扩展加载和跨网站兼容性仍需结合安装后的真实网页验证。

1.1.0 验证记录：62 项扩展测试与原游戏的 11 项测试全部通过，类型检查及两种生产构建通过。浏览器验证了轻点摸摸、真实拖动、指定下一口、诱饵吞噬与 Esc 取消；怪物实际成长至最终形态，停止后原网页控件、事件和输入内容可恢复。五形态图鉴和弹窗也通过了视觉检查。

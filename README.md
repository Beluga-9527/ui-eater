# 吞噬 UI 的怪物 · UI EATER

一款在虚拟电脑桌面中游玩的 HTML5 创意解谜游戏。按钮是食物，窗口是工具，鼠标也可能成为威胁。你需要移动诱饵、保护关键控制台，把这只爱吃界面的小怪物引进笼子。

完整 MVP 包含 3 个可通关关卡。使用 Vite、React、TypeScript、CSS 与 GSAP；纯前端运行，无登录、支付、后端或模型 API。怪物只能影响游戏中的虚拟桌面。

## Chrome 浏览器扩展版

另外提供可在普通 HTTP/HTTPS 网页中游玩的 Manifest V3 扩展。扩展默认不注入任何页面；打开弹窗只查询状态，点击「开始游戏」才注入并开始随机吞噬当前视口内的按钮、链接、文字和图片。支持拖动、轻点怪物，使用网页控制条投喂诱饵或指定下一口，让它按你的意图探索页面。每吃掉一个元素或诱饵获得 1 XP，在累计 3 / 7 / 12 / 18 XP 时进化，依次长出嫩芽、双角、翅膀和王冠，同时变色、变大。

支持暂停、继续和「停止并恢复网页」，保留网页原节点、事件和输入内容。暂停保留成长；停止后重新开始、刷新或导航到新页面会重置成长，并需要手动开始。弹窗显示当前形态、成长进度和吞噬计数。

```sh
npm install
npm run build:extension
npm run test:extension
```

构建结果位于 `dist-extension/`。在 Chrome 的 `chrome://extensions` 页面开启开发者模式，点击「加载已解压的扩展程序」，选择该文件夹。更新已安装的旧版时，在扩展管理页重新加载扩展，再刷新当前网页。详细使用方法、权限与支持范围见 [扩展说明](extension/README.md)。此扩展不需要启动 Vite 服务或使用 Sites 托管。

权限只有 `activeTab` 和 `scripting`，按手动点击临时访问当前标签页，不申请长期全站读取权限。Chrome 内部页面、扩展商店、PDF 浏览器与跨域 iframe 等存在平台限制，不承诺任意网站的任意组件均可吞噬。表单、输入框、编辑器、大型布局容器与扩展自己的控件受到保护。

`extension/qa.html` 和 `qa.ts` 是本地浏览器验证页，模拟扩展消息通道，直接运行相同的网页控制器；它们不会被打入扩展发布目录。自动测试验证核心状态机、投喂与目标选择、进化阈值、真实 DOM 恢复及弹窗 API 调用顺序，但不等同于在实际 Chrome 中逐一验证所有网站。

## 本地运行

建议使用 Node.js 22.12 或更高版本及 npm。在本目录打开终端：

```sh
npm install
npm run dev
```

打开终端显示的本地地址，通常为 `http://localhost:5173`。开发服务器支持热更新。

```sh
npm test            # 运行游戏规则与关卡模拟测试
npm run typecheck   # TypeScript 类型检查
npm run build       # 类型检查并生成 dist/ 生产版本
npm run preview     # 本地预览已构建的 dist/
```

优先使用桌面版 Chrome、Edge、Firefox 或 Safari。界面面向鼠标与键盘，推荐 1366 × 768 及以上分辨率；游戏桌面会按可用宽度缩放。

## 如何操作

| 操作 | 作用 |
| --- | --- |
| 拖动黄色诱饵按钮 | 改变怪物的目标，把它引向捕获区域 |
| 点击仍然存在的可吞噬按钮 | 发出声音，吸引怪物追逐这个按钮 |
| 拖动可移动窗口的标题栏 | 移动窗口及其内容；紫色防护窗口可作为障碍 |
| 点击「关闭笼门」或按 `Space` | 触发捕获；等待怪物完整进入区域及绿色状态提示 |
| 点击暂停或按 `P` | 暂停 / 继续游戏 |
| 点击外层「重启关卡」或按 `R` | 恢复当前关卡的全部对象、诱饵和捕获机会 |
| 点击关卡入口 | 切换到对应关卡 |
| 点击声音、全屏、帮助按钮 | 切换合成音效、进入 / 退出全屏、查看操作指南 |

把诱饵拖到右下方笼子内部，然后等待怪物跟进去。笼门不会自动关闭，必须由玩家在合适的时机操作。被吞掉的按钮会从桌面消失，也不能再次吸引怪物；诱饵是可再生资源，被吃掉后会补充。

### 01 · 贪吃的按钮

从一个简单桌面开始。怪物苏醒后会自主寻找、追逐并吞掉按钮。拖动诱饵引它进笼，再关闭笼门。这一关的欢迎窗口固定，捕获失误可以无限重试。

### 02 · 消失的控制台

控制台和防护窗口都可以拖动。移动控制台可以带走其中的按钮，移动紫色防护窗口可以改变怪物的行进路线。保护「捕获电源」并利用诱饵完成捕获；电源被吞掉会导致本次挑战失败。

### 03 · 怪物学聪明了

怪物速度更快，靠近的光标会使它进入逃离状态。放好诱饵后及时移开光标，利用两个障碍窗口保护控制台。这一关只有 3 次关门机会，空笼关门会消耗一次机会，连续点击受冷却时间保护。

所有失败都可以通过游戏外层的重启入口恢复。这个入口不属于可吞噬桌面，关键电源损坏或捕获次数耗尽也不会形成永久死局。

## 项目结构

```text
src/
├── App.tsx                # 关卡选择、控制栏、帮助、胜利与失败界面
├── main.tsx               # React 入口
├── styles.css             # 桌面、窗口及响应式布局
├── components/
│   ├── Desktop.tsx        # 游戏桌面、真实拖动及碎屑反馈
│   ├── Icon.tsx           # 统一的 SVG 图标
│   ├── Monster.tsx        # 六种表情状态的像素怪物
│   └── Monster.css        # 眨眼、咀嚼、受惊等动画
└── game/
    ├── useGame.ts         # requestAnimationFrame 与 React 同步
    ├── sound.ts           # 无外部音频的 Web Audio 合成音效
    ├── types.ts           # 游戏状态、窗口、对象、关卡类型
    ├── levels.ts          # 三关配置、尺寸与初始对象
    ├── engine.ts          # 主模拟循环、输入、捕获、暂停和重启
    ├── stateMachine.ts    # 规则驱动的目标选择与鼠标逃离判断
    ├── objects.ts         # 可吞噬对象与窗口移动管理
    ├── collision.ts       # 边界、碰撞、障碍绕行与捕获判定
    └── engine.test.ts     # 规则和真实移动路径的模拟测试
public/
└── favicon.svg            # 手绘像素怪物图标
```

React 界面负责呈现桌面、拖动交互、快捷键与界面动画。`requestAnimationFrame` 向独立的 `GameEngine` 提供时间步长；引擎不依赖 DOM，便于测试与扩展。过大的帧间隔会被限制，避免后台标签恢复时怪物突然跳跃。窗口和诱饵坐标始终限制在桌面内。

状态机包含 `IDLE`、`SEARCH`、`CHASE`、`EAT`、`ESCAPE`、`CAPTURED`。吃掉对象会改变游戏数据，并由界面移除对应控件，而不只是播放隐藏动画。紫色窗口参与障碍碰撞与路径选择，普通控制台里的按钮仍可被怪物吞噬。

## 测试范围

`npm test` 使用 Node 测试运行器执行纯模拟测试，覆盖：

- 自主搜索、追逐、吞噬，以及被吞按钮不能再次触发。
- 暂停后的时间和交互冻结、历史状态快照不被后续更新修改。
- 边界限制、无效输入与大帧间隔保护。
- 窗口及内部按钮联动、移动障碍时的怪物安全避让。
- 三个关卡通过移动诱饵、实际行走及笼门捕获完成通关。
- 第三关鼠标逃离、捕获次数、冷却，以及重启恢复。
- 关键电源被吞噬后的失败与恢复。

这些测试验证规则和可通关性。浏览器中的拖动手感、声音、全屏及动画需要结合实际页面体验检查；类型检查和生产构建通过不等同于所有浏览器均已逐一验收。

本次验证：11 项自动测试通过，TypeScript 检查和生产构建通过。内置 Chromium 浏览器以 1366 × 768 验证了三关的真实诱饵拖动及关门通关，验证了防护窗口拖动、暂停与重启。未逐一验证所有浏览器及声音/全屏权限组合。已完成关卡会保存在浏览器本地存储中。
